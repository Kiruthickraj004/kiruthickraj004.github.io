# Kiruthickraj — Full-Stack Developer Portfolio

A clean, minimalist developer portfolio built with **React** and **Tailwind CSS v3**, focused on clear typography, fast load times, and distraction-free presentation of full-stack engineering work.

🌐 **Live URL**: [https://kiruthickraj004.github.io](https://kiruthickraj004.github.io)  
📫 **Contact**: [kiruthickraj28@gmail.com](mailto:kiruthickraj28@gmail.com)  
🐙 **GitHub**: [@kiruthickraj004](https://github.com/kiruthickraj004)

---

## ⚡ Core Technical Stack

- **Backend**: Python (Django, Django REST Framework), PHP (Laravel)
- **Frontend**: ReactJS, JavaScript (ES6+), Tailwind CSS v3
- **Databases & Caching**: PostgreSQL, MySQL, Redis
- **DevOps & Tooling**: Docker, Docker Compose, Postman, Git

---

## ✨ Features

1. **Minimalist Aesthetic**:
   - Clean, editorial typography with generous whitespace and zero visual clutter.
   - Purposeful micro-interactions with no distracting animations.

2. **Dual-Theme Mode (Dark / Light)**:
   - High-contrast, easy-on-the-eyes Dark Mode and clean Light Mode.
   - Smooth transitions and local storage persistence.

3. **Multi-Page Architecture**:
   - **Home**: Overview of background, skills matrix, selected systems, and direct contact options.
   - **About**: Architectural principles, deep-dive into the technical stack, and career history.
   - **Projects**: Filterable catalog of full-stack systems with an Architecture Blueprint viewer and interactive REST API explorer.
   - **Contact**: Quick-copy email, GitHub profile connection, and direct inquiry form.

4. **GitHub Pages & CI/CD**:
   - Automated GitHub Actions workflow configured in `.github/workflows/deploy.yml`.

## 🚀 Local Development Setup

```bash
# Clone the repository
git clone https://github.com/kiruthickraj004/kiruthickraj004.github.io.git
cd kiruthickraj004.github.io

# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build
```
